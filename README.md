# BrandRadar — Digital Threat Command Center

Hackathon-ready Streamlit prototype for explainable brand impersonation and digital-threat investigation.

## Features
- Universal Investigator for brands, look-alikes, usernames and URLs
- Visual Shield image comparison
- Threat DNA multi-signal scoring
- Domain Intelligence with live retrieval and offline fallback
- Social/App threat surface views
- Attack Simulator
- Threat Fusion Engine
- Investigation Report with download
- Threat Network relationship graph
- Synthetic Model Evaluation
- Trusted-brand target integrity for cross-brand candidates

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo note
BrandRadar uses controlled/local intelligence for the demo. It is an investigation aid and not a legal or final fraud verdict.
